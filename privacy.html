Faceless Ops privacy policy

Last updated: 19 October 2026

Faceless Ops is a private tool used only by the owner of the Invisible Edu Guru channel to upload and schedule that channel's own videos. It is not offered to the public.

What data it uses

With the owner's permission, it uses the YouTube Data API and YouTube Analytics API to upload videos, set their titles, descriptions and privacy settings, and read the channel's own view statistics.

How the data is stored

The sign-in token is stored only on the owner's own computer. No data from Google accounts is sold, shared with third parties, or used for advertising.

Google API Services

Faceless Ops' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also follows the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Use the contact email on the Invisible Edu Guru YouTube channel.
